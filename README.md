# 🥣 Blue Recipe Assistant

An Agentic AI recipe recommendation application built with LangGraph and Python. 

This project uses a multi-agent architecture to converse naturally with users, extract their available ingredients and dietary constraints, dynamically generate SQL queries to search a recipe database, and self-correct its own responses to prevent hallucinations.



## 🚀 Current Features

* **Conversational Extraction:** A smart agent that chats with the user to incrementally gather required parameters (ingredients, time limits, calories) using structured Pydantic outputs.
* **Text-to-SQL Generation:** Automatically maps extracted JSON constraints to a database schema to execute safe, accurate searches.
* **Verifier:** A self-correcting loop where a Verifier Agent reviews the drafted recipe pitch against the user's constraints and the database results, forcing a rewrite if it detects a hallucination.
* **Terminal UI** Includes scripts for running the conversational loop directly in the terminal for now.

## 🛠️ Tech Stack

* **Orchestration:** [LangGraph](https://python.langchain.com/docs/langgraph) & LangChain
* **LLMs:** OpenAI (`gpt-4o-mini`) via `langchain-openai`
* **Database:** PostgreSQL
* **Frontend:** Streamlit (working)

This is an ongoing project. Planned features include:
